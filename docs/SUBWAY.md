# 지하철 서랍 (My Doc)

헤더의 '지하철' 서랍은 프로필 없이 바로 열리며, 하위 탭으로 '경로 탐색'과 '실시간 위치'가 있습니다.

## 노선도·경로

실제 역 위치(위도·경도)로 그린 서울 지하철 1~9호선 노선도에서 역을 눌러 출발·경유·도착을 정하고, 경로를 앱 안에서 직접 계산합니다. 경로 계산은 인증키 없이 동작하며 결과는 표준 운행시간 기반 추정치입니다. 출발역의 다음 열차는 서울 열린데이터광장 인증키가 있을 때 시간표로 보여줍니다.

## 화면

- 노선도: 드래그로 이동, 휠·두 손가락으로 확대·축소, +/−/⤢ 버튼. 기본 화면은 서울 도심이고 외곽 노선은 이동해서 봅니다. 확대할수록 환승역 → 모든 역 순으로 이름이 보입니다.
- 역을 누르면 출발·경유·도착 버튼이 나옵니다. 같은 버튼을 다시 누르면 해제되고, 한 역은 한 역할만 가집니다. 입력칸에 역 이름을 직접 써도 됩니다.
- 출발과 도착이 정해지면 바로 경로를 찾고, 지도에 경로를 노선 색으로 강조하며 경로 전체가 보이게 맞춥니다. 경로 밖 노선과 역 이름은 흐리게 처리합니다.
- 공식 노선도 디자인을 옮긴 것이 아니라 역 좌표로 직접 그린 지도입니다.

## 구성

| 파일 | 역할 |
| --- | --- |
| `apps/subway/data-src/*.csv` | 내려받은 공공데이터 원본(UTF-8로 변환) |
| `apps/subway/build-data.mjs` | 원본을 노선·구간·환승 데이터와 혼잡도로 조립 (`npm run build:subway`) |
| `public/subway/subway-data.json` | 조립 결과. 화면이 처음 지하철 탭을 열 때 불러옴(서버도 경로 계산에 사용) |
| `apps/subway/subway.mjs` | 역 이름 정리, 역 검색, 다익스트라 경로 계산 (브라우저·테스트 공용) |
| `public/subway/subway-view.js` | 지하철 화면(노선도, 출발·경유·도착, 결과 시트·탈 열차, 실시간 위치·역 정보, 홈 브리핑 카드) |
| `apps/subway/routes.mjs` | 지하철 API 경로(`/api/subway/*`) |
| `apps/subway/subway-api.mjs` | 서버: 서울시 시간표로 출발역의 다음 열차 계산 (`/api/subway/departures?station=`), 실시간 열차 위치 (`/api/subway/positions?line=`) |

## 계산 방식

- 역은 노선별 점(`호선|역명`), 이웃 역은 운행시간 선, 같은 역의 다른 노선은 환승 선으로 연결합니다.
- 거리만 있는 구간의 시간: `0.40 + 1.05 × 거리(km)`분. 서울교통공사 271개 구간의 표준 운행시간을 거리로 회귀한 식이며 평균 오차는 약 0.3분입니다. 이런 구간을 지나면 결과에 '거리로 추정' 안내가 붙습니다.
- 정차시간: 역마다 0.5분. 표준 운행시간 합으로 2호선 순환이 65분이지만 실제는 약 87~90분이라, 43개 정차 × 0.5분으로 맞춥니다.
- 환승: 도보시간(서울교통공사 자료, 없으면 3분) + 평균 대기 3분. 출발역에서의 대기는 넣지 않습니다.
- 최소 환승 모드는 환승 1회를 15분처럼 무겁게 계산해 경로를 고르고, 표시 시간은 실제 추정 시간입니다.
- 6호선 응암순환(응암→역촌→불광→독바위→연신내→구산→응암)은 한 방향으로만 운행하도록 계산합니다.
- 역 이름은 괄호 부기명을 빼고 통일합니다(예: 흑석(중앙대입구)→흑석). 4호선 총신대입구와 7호선 이수는 같은 역으로 합칩니다.
- 경유: 출발→경유, 경유→도착을 각각 찾아 잇습니다. 경유역에서 같은 노선을 같은 방향으로 계속 타면 한 구간으로 합치고, 아니면 경유역 환승(도보 + 대기)을 더합니다.
- 좌표: 서울교통공사 좌표를 우선하고 없으면 국가철도공단 좌표를 씁니다. 원본에 없는 역(현재 암사역사공원)은 같은 구간의 이웃 역 위치를 운행시간 비율로 연장해 추정하고 `approxCoords`에 기록합니다.

## 한계

- 급행(1호선·9호선), 실제 배차 간격, 지연, 막차는 반영하지 않습니다.
- 1호선의 경인·경부·광명·서동탄 방면을 같은 노선으로 보아, 실제로는 구로·금천구청·병점에서 열차를 갈아타야 하는 경우도 환승 0회로 나올 수 있습니다.
- 원본에 없는 구간: 4호선 진접선(별내별가람~진접), 8호선 별내선 연장(구리~별내).
- 원본에 없어 추정한 거리: 서울역→남영 1.7km, 남태령→선바위 1.8km.
- 서울교통공사 운행시간 자료는 2024년 8월 기준입니다.

## 탈 열차 (인증키 필요)

경로가 정해지면 '지금 출발' 또는 '출발 시각 지정' 기준으로 구간마다 탈 열차를 시간표에서 고릅니다(`/api/subway/plan?from=&via=&to=&mode=&time=HH:MM`).

- 타는 역 시간표에서 기준 시각 이후 열차를 순서대로 보고, 내리는 역 시간표에서 같은 열차번호의 도착 시각을 찾습니다. 반대 방향(도착이 출발보다 이르거나 너무 늦음)과 내리는 역에 서지 않는 열차(급행 통과)는 건너뜁니다.
- 2호선 순환열차는 성수를 지나면 열차번호가 바뀌므로, 같은 방향(내선 1·외선 2)에서 예상 도착 ±4분 안의 가장 가까운 도착 시각을 씁니다.
- 내리는 역 시간표가 없으면 행선지가 내리는 역 너머인지 노선을 따라 확인하고, 도착은 표준 운행시간으로 추정해 '(예상)'으로 표시합니다.
- 환승: 앞 구간 도착 + 도보시간 이후의 첫 열차. 다음 열차 2대를 '놓치면'으로 함께 보여줍니다.
- 역사마스터의 노선명(경부선·경인선·경원선·장항선 → 1호선, 일산선 → 3호선, 과천선·안산선·진접선 → 4호선, 별내선 → 8호선, 9호선(연장) → 9호선)을 1~9호선으로 맞춥니다.
- '초기화' 버튼은 출발·경유·도착·경로·출발 시각을 지우고 지도를 처음 화면으로 돌립니다.

## 역 실시간 도착정보 (실시간 지하철 키)

실시간 위치 탭에서 역을 누르면 서울시 실시간 도착정보(`realtimeStationArrival`)로 방면별 도착 안내를 보여줍니다(`/api/subway/arrivals?station=`, 역별 20초 캐시).

- 표시: 방면(예: 상계방면), 남은 시간(수신 후 지난 시간을 빼서 계산, 1분 미만은 '곧 도착'), 행선지, 열차번호, 급행·막차, 원문 안내(예: '7분 후 (수유)', '전역 도착').
- 역 이름이 다른 경우: 서울역→서울, 총신대입구→총신대입구(이수), 당고개→불암산. 그래도 결과가 없으면 역사마스터의 원래 이름(괄호 포함)으로 한 번 더 찾습니다.
- 실시간 위치와 같은 키를 써서 하루 1,000건 제한을 함께 씁니다.

## 평소 혼잡도 (파일 자료)

`apps/subway/data-src/seoulmetro-congestion.csv`(서울교통공사 지하철혼잡도정보, 공공데이터포털 15071311, 2026년 9월 기준)를 `npm run build:subway`로 `apps/subway/subway-congestion.json`(서버 전용)으로 만듭니다.

- 1~8호선 서울교통공사 역, 평일·토요일·일요일, 상선(내선)·하선(외선), 05:30~00:30 30분 단위 평균. 값은 정원(좌석+입석) 대비 %입니다.
- 단계: 35% 미만 여유(약 34%면 좌석이 다 찬 정도), 80% 미만 보통, 130% 미만 붐빔, 그 이상 매우 붐빔.
- 역 도착정보의 방면마다 지금 시간대 값을, 탈 열차 안내의 구간마다 탑승 시각 기준 구간 내 가장 붐비는 역의 값을 보여줍니다.
- 9호선·코레일·인천 구간은 자료가 없습니다. 실시간 혼잡도가 아니라 평소 평균입니다.

## 프로필 저장 (즐겨찾기·최근 경로)

Cloth to You 프로필(닉네임)을 쓰고 있으면 지하철 저장분도 같은 프로필에 저장되어 다른 기기에서 이어집니다. 프로필이 없으면 이 기기(브라우저)에만 저장합니다.

- 저장 항목: 최근 경로 8개, 즐겨찾기 경로 12개(경로 결과의 '☆ 즐겨찾기'), 경로 기준(최단 시간/최소 환승), 실시간 위치에서 고른 노선.
- 서버: `POST /api/subway/save {userId, subway}`. 역 이름은 노선도 이름으로 정리하고, 없는 역·출발=도착·중복 경로는 버립니다. 프로필 JSON(`wq_profiles.data`)의 `subway` 항목에 저장하며, 옷차림 설정을 저장할 때도 이 항목은 유지합니다.
- 프로필을 불러오면 서버 저장분과 이 기기 저장분을 합치고(서버 우선), 바뀐 내용은 0.8초 뒤 서버에 저장합니다.
- 홈의 지하철 카드에는 즐겨찾기(★)가 먼저, 그다음 최근 경로가 보입니다.

## 모바일 화면

- 모바일 지하철 화면은 한 화면 안에서 쓰도록 큰 제목과 푸터를 숨깁니다.
- 경로 탐색은 위쪽 전환으로 두 가지 방법 중 하나를 고릅니다.
  - 지도에서 고르기: 출발·도착 입력 상자와 노선도만 보여주고, 노선도가 남은 공간을 채웁니다(페이지 스크롤 없음). 처음에는 출발역을 고르는 모드이며, 역(점이나 이름)을 누르면 출발 → 도착 순서로 채워집니다.
  - 역 검색: 노선도 없이 입력 상자, 경로 찾기·초기화, 즐겨찾기·최근 경로를 보여줍니다.
- 경로를 찾으면 결과가 아래에서 올라오는 시트로 뜹니다. 시트 안에서 최단 시간·최소 환승, 지금 출발·시각 지정, 즐겨찾기, 탈 열차, 역별 경로를 봅니다. 시트를 접으면 '약 N분 · 환승 N회' 막대만 남습니다.
- 실시간 위치는 오른쪽 아래에 새로고침(↻)과 '호선 변경' 버튼을 둡니다. 열차 목록 보기는 숨겼습니다.
- 데스크톱은 노선도와 패널을 나란히 두고, 경로 기준·출발 시각은 결과 요약 아래에 있습니다.

## 출발역 다음 열차 (인증키 필요)

`SEOUL_OPENAPI_KEY`(서울 열린데이터광장 일반 인증키)를 설정하면 출발역을 고를 때 노선·방향별로 지금 이후 가장 가까운 열차 3대(출발 시각, 몇 분 후, 행선지)를 보여줍니다.

- 역 이름 → 노선별 역 코드는 역사마스터 API(하루 캐시), 시간표는 역별 시간표 API(요일·방향별 12시간 캐시)를 씁니다.
- 요일은 한국 시간 기준 평일·토요일·일요일로 고르며 공휴일은 구분하지 않습니다(공휴일에는 평일 시간표가 나올 수 있음).
- 종착역 도착만 있는 행은 제외하고, `24:05`처럼 자정을 넘긴 시각은 `00:05`로 표시합니다. 급행 표시는 시간표의 급행 구분값(Y/E)을 따릅니다.
- 키가 없으면 서버가 `needsKey`를 돌려주고 화면은 연결 안내만 보여줍니다. 시간표는 계획값이라 실제 도착과 다를 수 있습니다.

설정 위치: 로컬은 `.env.local`의 `SEOUL_OPENAPI_KEY=...` 후 `node --env-file=.env.local server.mjs`, 배포는 Vercel 환경변수에 같은 이름으로 등록 후 재배포.

## 실시간 위치 (인증키 필요)

`SEOUL_SUBWAY_KEY`(서울 열린데이터광장 **실시간 지하철** 인증키, 일반 인증키와 별도)를 설정하면 '실시간 위치' 탭에서 노선별 열차 위치를 봅니다.

- 노선(1~9)을 고르면 역 목록을 세로 띠로 그리고, 열차를 방향별 칸(▲ 시작역 방면 / ▼ 끝역 방면, 2호선은 외선·내선순환)에 놓습니다. 진입·도착·출발·접근 중 상태에 따라 역 위나 역 사이에 표시합니다.
- 출발역이 그 노선에 있으면 '○○에 오는 열차'로 방향별 가장 가까운 열차의 남은 정거장과 예상 시간(구간 운행시간 + 정차 0.5분)을 보여줍니다. 출발역 전에 끝나는 열차는 뺍니다.
- 방향: 실시간 자료의 상하행 값(`updnLine`)은 0이 노선 데이터의 시작역 쪽이고, 2호선만 반대(0=내선=정방향)입니다. 같은 구간 안에 행선지가 있으면 행선지 쪽을 우선합니다.
- 갱신: 화면이 보이는 동안 20초마다, 10분이 지나면 자동 갱신을 멈춥니다. 서버는 노선별 15초 캐시를 둡니다. 실시간 API는 하루 1,000건 제한입니다.
- 4호선 당고개는 실시간 자료에서 새 이름 불암산으로 오므로 같은 역으로 맞춥니다. 노선 데이터에 없는 역(1호선 지제, 8호선 별내선 장자호수공원·다산 등)에 있는 열차는 표시하지 않고 안내만 합니다.
- 열차를 누르면 열차 정보(열차번호, 행선지, 현재 위치·상태, 방향, 급행·막차, 출발역까지 예상, 위치 수신 시각)를 카드로 보여주고, '열차 목록'으로 모든 열차를 표로 볼 수 있습니다. 열차번호는 운행 편성 번호이며 객차 번호는 공개 자료에 없습니다.
- 서버 경로: `/api/subway/positions?line=2`. 키는 서버에서만 쓰고 화면 코드에는 넣지 않습니다.
