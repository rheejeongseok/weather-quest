# 기온·옷차림 점수 근거 재점검

## 확인한 1차 자료

- [ASHRAE Handbook, Thermal Comfort](https://handbook.ashrae.org/handbooks/f17/si/F17_Ch09/f17_ch09_si.aspx): 의복 단열량, 활동량, 환경 조건을 함께 고려합니다. 실내 쾌적 모델과 전신 착의 단열량을 실외 상의 조합 점수와 동일하게 볼 수 없습니다.
- [UC Berkeley CBE Outdoor Comfort](https://cbe-berkeley.gitbook.io/clima/documentation/tabs-explained/outdoor-comfort): UTCI는 기온뿐 아니라 복사온도·바람·습도 및 의복·활동 가정을 사용합니다. 현재 앱은 UTCI를 계산하지 않습니다.
- [체코공과대학 의복 단열 교육 표](https://tzb.fsv.cvut.cz/files/vyuka/se20/web/comfort/thermal/cfs/content/cont3t.html): 개별 의복 분류와 두께 차이를 참고할 수 있습니다. 특정 제품 실측값이나 한국 사용자 착장 분포는 아닙니다.

## 재점검 결론

이번 조사에서 한국 사용자에 대해 기온·개별 착장·개인 체감을 함께 기록하고 현재 상의 점수로 직접 환산 가능한 공개 통계 데이터는 확보하지 못했습니다. 인터넷의 흔한 기온별 옷차림 그림을 실제 관찰 데이터나 기상청 표준으로 인용하지 않았습니다.

옷별 상대 점수와 날씨별 목표 점수는 서로 다른 문제입니다. 의복 단열 표로 두께 순서를 검토할 수 있지만, 전신 단열량을 상의 합계에 바로 넣거나 실내 관찰식을 실외 추천에 그대로 적용하면 과도한 정확성을 주장하게 됩니다. 따라서 기존 기본 기울기 0.3과 상수 26을 관찰 데이터로 재학습했다고 주장하거나 근거 없이 교체하지 않았습니다. UI에서 초기 가설임을 명시하고 계산식·보정·유사 기온 기록 수를 확인할 수 있게 했습니다.

## 현재 계산과 다음 검증

`목표 = 기온 기준 + 개인 보정 + 활동량 + 야외 시간`, 범위 1~12입니다. 기온 기준은 `1 + (26 - 체감온도) × 0.3`입니다. 체감온도에 이미 바람 영향이 있으므로 바람 민감도를 다시 더해 이중으로 보정하지 않습니다. 바람 민감도는 방풍 후보 순위에 사용합니다. 땀·이동수단은 조절 안내로만 사용합니다.

추위·더위 초기 추정은 각각 쌀쌀한/따뜻한 조건에서 더 많이 반영합니다. 실제 피드백의 개인 보정은 기록 당시 활동량과 야외 시간을 분리합니다. 야외 시간의 ±0.4점 등 세부 계수도 검증 중인 앱 가설입니다.

개인 기록이 쌓이면 체감온도 구간별 ‘적당함’ 비율과 ‘많이 추움/많이 더움’ 비율, 목표 대비 착용 점수 차이를 확인해야 합니다. 모델 갱신의 효과는 학습에 쓴 같은 기록을 다시 평가하는 대신 이후 실제 외출 기록으로 비교해야 합니다. 현재 자동 테스트는 방향·일관성·저장 동작의 검증이며, 사용자 추천 정확도의 실증 검증이 아닙니다.
