# 보온 분류 v2

## 참고한 자료와 적용 범위

- 체코공과대학 공개 열쾌적 교육 자료의 [의복 단열 참고표](https://tzb.fsv.cvut.cz/files/vyuka/se20/web/comfort/thermal/cfs/content/cont3t.html): 얇은/보통/플란넬 셔츠, 얇은/보통/두꺼운 스웨터를 구분한 수치를 참고했습니다. 이는 최신 표준 원문 전체를 검증한 것이 아니며 제품 측정 데이터도 아닙니다.
- REI의 [충전재 선택 안내](https://www.rei.com/learn/expert-advice/insulated-outerwear.html): 필파워와 충전량을 구분하고 부피·충전재·젖음·활동을 따로 고려합니다.

## 앱에서의 처리

일반 직물 일부는 참고 clo의 상대 크기를 10배해 앱 점수로 사용합니다. 반팔, 긴팔, 플리스, 셸, 패딩 등은 제품 차이가 커 설계상 추정치를 사용합니다. 전체 항목을 실측 데이터처럼 취급하지 않습니다. 실제 적용 수치는 `lib.mjs`의 `variants`가 기준입니다.

점수는 소재 이름만으로 배율을 부여하지 않습니다. 셔츠·니트·가디건·후드집업의 두께, 기모·파일, 안감, 패딩의 부피를 선택합니다. 다운/합성 충전재를 따뜻함의 단일 순위로 놓지 않으며, 필파워만 입력해서 점수를 계산하지 않습니다.

상의의 점수 합계는 전신 착의 단열량이 아닙니다. 겹침·공기층·압축을 정밀 모델링하지 않으며, 바람 차단은 별도 속성입니다. 현재 바람 차단은 바람막이/패딩 분류의 기본 가정이며 특정 제품의 방풍 성능을 보증하지 않습니다. 온도별 목표 점수는 기존 휴리스틱으로 유지하며 표준 PMV/실외 열쾌적 모델에서 산출한 값이 아닙니다.

## 기록 호환성

새 기록에 `scoreVersion: 2`, `itemOptions`, `garments` 스냅샷을 저장합니다. 기존 기록은 원래 점수를 표시하고 '이전 기준'으로 표시합니다. 개인화 계산 시 기존 기록은 새 기본 분류로 환산하여 점수 체계 변경이 추위·더위 민감도로 오인되지 않게 합니다. 과거에 두께를 기록하지 않았으므로 기본 두께로만 추정 가능합니다. JSON 가져오기에서도 구버전 원점수를 보존합니다. DB 스키마 변경은 필요하지 않습니다.
