# 보온 분류 v3

## 참고한 자료와 적용 범위

- 체코공과대학 공개 열쾌적 교육 자료의 [의복 단열 참고표](https://tzb.fsv.cvut.cz/files/vyuka/se20/web/comfort/thermal/cfs/content/cont3t.html): 얇은/보통/플란넬 셔츠, 얇은/보통/두꺼운 스웨터를 구분한 수치를 참고했습니다. 이는 최신 표준 원문 전체를 검증한 것이 아니며 제품 측정 데이터도 아닙니다.
- REI의 [충전재 선택 안내](https://www.rei.com/learn/expert-advice/insulated-outerwear.html): 필파워와 충전량을 구분하고 부피·충전재·젖음·활동을 따로 고려합니다.
- v3 비교 자료: [pythermalcomfort 개별 의복 표](https://pythermalcomfort.readthedocs.io/en/latest/documentation/clothing.html), [Engineering ToolBox 의복 단열 표](https://www.engineeringtoolbox.com/clo-clothing-thermal-insulation-d_732.html). 두 자료 모두 ISO 9920·ASHRAE 계열 값을 옮긴 2차 자료이며 원 출처를 항목별로 밝히지 않습니다. 표준 원문(유료)은 확인하지 않았습니다.

## 앱에서의 처리

일반 직물 일부는 참고 clo의 상대 크기를 10배해 앱 점수로 사용합니다(1점 ≈ 0.1 clo). 반팔, 플리스, 셸, 경량패딩 등은 제품 차이가 커 설계상 추정치를 사용합니다. 전체 항목을 실측 데이터처럼 취급하지 않습니다. 실제 적용 수치는 `apps/cloth/lib.mjs`의 `variants`가 기준입니다.

점수는 소재 이름만으로 배율을 부여하지 않습니다. 셔츠·니트·가디건·후드집업의 두께, 기모·파일, 안감, 패딩의 부피를 선택합니다. 다운/합성 충전재를 따뜻함의 단일 순위로 놓지 않으며, 필파워만 입력해서 점수를 계산하지 않습니다. 마른 상태의 보온은 섬유 종류보다 두께와 갇힌 공기의 영향이 크고, 소재 차이는 주로 땀·젖음·바람에서 나타나기 때문입니다.

상의의 점수 합계는 전신 착의 단열량이 아닙니다. 겹침·공기층·압축을 정밀 모델링하지 않으며, 바람 차단은 별도 속성입니다. 현재 바람 차단은 바람막이/패딩 분류의 기본 가정이며 특정 제품의 방풍 성능을 보증하지 않습니다. 온도별 목표 점수는 기존 휴리스틱으로 유지하며 표준 PMV/실외 열쾌적 모델에서 산출한 값이 아닙니다.

새 옷 추가는 기존 옷의 점수를 바꾸지 않으므로 점수 체계 버전(3)을 유지합니다.

## 기록 호환성

새 기록에 `scoreVersion: 3`, `itemOptions`, `garments` 스냅샷을 저장합니다. 이전 버전(1·2) 기록은 저장 당시 점수를 그대로 표시하고 '이전 기준'으로 표시합니다. 개인화 계산 시 이전 버전 기록은 저장된 소재·두께 선택(`itemOptions`)으로 현재 점수를 다시 계산하여, 점수 체계 변경이 추위·더위 민감도로 오인되지 않게 합니다. v1 기록은 두께를 기록하지 않았으므로 기본 두께로만 추정합니다. JSON 가져오기는 버전 1~3을 받으며 원래 점수와 버전 번호를 보존합니다. DB 스키마 변경은 필요하지 않습니다.

기록 당시 저장한 추천 스냅샷(`recommendation`)의 범위 판정은 저장 시점의 점수 체계 기준이며 다시 계산하지 않습니다.
