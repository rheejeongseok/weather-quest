# 목표 보온량과 추천 검증

현재 추천은 검증 중인 규칙 기반 모델입니다. 자동 테스트는 계산의 방향과 데이터 흐름을 검증하며, 실제 착용 정확도를 보장하지 않습니다.

## 계산 순서

1. 설정한 외출 시각의 체감온도에서 기온 기준 보온량을 구합니다: `1 + (26 - 체감온도) × 0.3`, 범위 1~12.
2. 실외 기록에서 실제 입은 보온량, 5단계 체감, 당시 활동량으로 적정 보정값을 추정합니다. 체감 한 단계는 0.8점으로 가정합니다.
3. 추천 대상 체감온도에 가까운 기록의 비중을 높입니다. 가중치는 온도 차이를 5℃ 폭으로 둔 가우시안입니다. ±5℃ 이내의 기록 수를 화면에 함께 보여줍니다.
4. 초기 민감도 설정은 기록 약 두 개에 해당하는 비중을 갖습니다. 기록이 쌓일수록 개인 실측 피드백 비중이 커집니다. 개인 보정은 ±4점으로 제한합니다.
5. 활동량 보정(많이 움직임 -1, 보통 0, 가만히 있음 +1)을 더합니다. 기록할 때 활동량을 저장하며 개인 민감도 학습에서 해당 효과를 분리합니다. 이전 기록의 활동량이 없으면 보통으로 가정합니다.
6. 필요한 보온량을 정한 다음 선호 스타일로 조합을 정렬합니다. ‘간단하게’는 적은 겹, ‘여러 겹으로’는 중간옷을 활용한 조합을 선호합니다. 스타일이 목표 보온량 자체를 바꾸지는 않습니다.

소재·두께의 기본값뿐 아니라 세부 변형도 추천 후보로 사용합니다. 추천한 변형을 화면에서 선택 상태로 복원하므로 표시 보온량과 실제 저장 점수가 일치합니다. 보온량 근접도를 스타일보다 우선하고, 방풍은 별도로 반영합니다.

## 기본값 예시: 개인 보정 0, 보통 활동

| 체감온도 | 목표 점수 |
|---|---|
| 25℃ | 1.3 |
| 20℃ | 2.8 |
| 15℃ | 4.3 |
| 10℃ | 5.8 |
| 5℃ | 7.3 |
| 0℃ | 8.8 |
| -5℃ | 10.3 |

이는 실제 기온별 복장 표준이 아닌 초기 가설입니다. 실제 운영에서는 ‘적당했어요’ 비율과 ‘많이 추움/많이 더움’ 비율을 온도 구간별로 보고 조정해야 합니다. 바람·일사·활동·핏·겹침의 영향을 완전히 모델링하지 않습니다.

## 기록 삭제

삭제는 해당 사용자의 날짜 기록을 제거하고 최소한의 날짜별 삭제 표시만 남깁니다. 옷·날씨·체감 데이터는 남기지 않습니다. 구형 중복이나 백업이 기록을 되살리는 것을 막기 위한 처리입니다. 삭제된 기록은 기록 목록·내보내기·개인화에 포함하지 않으며, 같은 날짜에 사용자가 명시적으로 다시 저장할 수 있습니다.

## 검증 항목

- 기온 하강에 따른 기본 목표 증가, 활동량 보정 분리
- 추움/더움 응답의 보정 방향, 비슷한 기온의 기록 우선, 실내 제외
- 기록 삭제 후 재계산, 다른 사용자 기록 보존, 백업으로 인한 재생성 방지
- 스타일별 겹 수 차이와 목표 보온량 유지
- 추천 변형과 화면 조합의 점수 일치
- 실제 브라우저의 탭 전환, 스타일 설정 저장, 기록 삭제와 기기별 레이아웃
