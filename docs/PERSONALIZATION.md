# 개인별 예상 보온 범위

예상 범위는 실제 착용 기록을 해석하는 앱의 비교용 안내입니다. 통계적 신뢰구간, 건강·체질 진단, 제품의 실측 보온 성능 또는 검증된 적정 의복량을 의미하지 않습니다.

## 1. 옷 점수와 개인 범위를 분리

옷 종류·소재·두께별 점수는 이번 변경에서 고정했습니다. 사용자의 피드백으로 옷 점수와 개인 민감도를 동시에 바꾸지 않습니다. 개인의 편안한 범위만 조정합니다. 기존 `scoreVersion: 2` 기록은 저장한 점수를 사용하고 이전 점수 체계의 기록은 현재 기본 분류로 환산해 참고합니다. 기존 기록 자체를 덮어쓰지 않습니다.

## 2. 비교할 기록 선정

- 현재 추천 시간의 체감온도와 ±5℃ 이내인 실외 기록만 사용합니다.
- 삭제·실내·잘못된 피드백·기온 차이가 큰 기록은 제외합니다.
- 날짜별 최신 기록 하나만 사용합니다. 수정으로 같은 기록의 영향력이 늘지 않습니다.
- 온도 차이는 3℃ 폭의 가우시안 가중치를 사용합니다.
- 활동량이 다르면 가중치 0.5, 야외 체류 시간이 다르면 0.65를 곱합니다. 관련 정보가 없는 이전 기록은 각각 0.8, 0.85를 곱합니다. 가중치는 초기 설계값입니다.
- 당시 활동량과 체류 시간의 앱 보정을 제거하고, 현재 활동량과 체류 시간의 보정을 더해 기록의 점수를 비교합니다. 이 보정도 실증 계수가 아닌 앱 가정입니다.

## 3. 적당했던 기록을 기준점으로 사용

‘적당했어요’ 기록의 가중 중앙값과 25~75% 분위수를 기준으로 범위를 형성합니다. 이상값에 덜 민감하게 중앙값을 사용합니다. 최소한의 여유 폭을 두고 0.5점 단위로 바깥쪽 반올림합니다.

기준점의 유효 가중치 합을 2로 나눈 값을 최대 1까지 사용해 임시 중심과 기록 중심을 혼합합니다. 두 개라는 기준은 정확도를 보장하는 표본 수가 아니라 초기 표시·혼합 규칙입니다. 조건이 다르거나 온도 차이가 있으면 같은 기록 개수라도 비중이 줄어듭니다. 기록 수를 정확도 백분율로 표시하지 않습니다.

충분한 비중의 적당했던 기록이 있으면 임시 공식보다 실제 착용 점수가 우선합니다. 학습한 범위를 기존 임시 목표의 12점 상한에 억지로 맞추지 않습니다. 입력 오류 방지를 위한 전체 비교 범위는 0.5~30점입니다.

## 4. 추움·더움은 방향 정보

‘추웠어요’는 그 조합보다 따뜻한 방향, ‘더웠어요’는 그 조합보다 가벼운 방향의 근거로 사용합니다. 체감 한 단계마다 0.8점처럼 일정한 점수로 변환하지 않습니다.

해당 방향 기록의 가중 중앙값에서 다음/이전 0.5점 단계로 경계를 설정합니다. 그 경계가 다른 방향이나 적당했던 기록과 충돌하면 좁은 범위를 강제로 확정하지 않습니다. 점수 간격 자체는 편의상 정한 앱의 해상도입니다.

## 5. 화면의 기록 상태

| 상태 | 뜻 |
| --- | --- |
| 임시 기준 | 비교 가능한 기록이 없어 기본 가정을 사용 |
| 기록을 알아가는 중 | 적당했던 근거가 있으나 아직 적어 임시 기준도 혼합 |
| 개인 기록 기준 | 비슷한 조건의 적당했던 기록이 주된 기준 |
| 착용감 방향만 참고 | 적당했던 기록 없이 추움·더움 방향만 확인 |
| 기록이 엇갈려요 | 비슷한 조건의 응답이 충돌해 확정적으로 안내하지 않음 |

모든 상태가 ‘정확함’을 뜻하는 것은 아닙니다. 화면에서 참고한 날짜, 실제 옷, 착용 점수, 체감온도와 피드백을 확인할 수 있습니다. 가장 관련 있는 기록을 먼저 보여주고 나머지는 접어서 표시합니다. 적당했던 조합은 버튼으로 다시 불러올 수 있습니다.

## 6. 기록이 없을 때의 출발점

기존 `1 + (26 - 체감온도) × 0.3`을 1~12로 제한한 값에 초기 민감도·활동량·야외 시간 가정을 적용합니다. 이 값은 임시 중심이며 보통 ±1점으로 넓게 출발합니다. 관찰 데이터로 학습한 기온별 표준이 아닙니다.

실제 기록이 쌓이면 임시 공식에 대한 작은 보정만 하는 대신, 적당했던 착용 점수 자체로 기준을 옮깁니다. 옷별 점수는 계속 고정합니다.

## 7. 스타일과 조합

자동 추천은 범위 밖의 차이를 먼저 줄이고, 범위 안에서는 간단하게/균형 있게/여러 겹으로 선호를 반영합니다. 비슷한 스타일과 보온 범위에 맞는 실제 편안했던 조합도 추천 후보로 참고합니다. 바람 차단은 별도로 고려합니다.

수동 조합은 범위 아래/안/위 중 어디에 있는지 비교합니다. 내부 정렬을 위한 중심점은 남지만 화면에서 정밀한 정답 점수처럼 강조하지 않습니다.

## 8. 삭제와 검증

삭제·수정 후 범위는 남은 기록으로 다시 계산합니다. 삭제 표시는 이전 중복이나 백업의 재생성을 막고, 옷·날씨·피드백 본문을 남기지 않습니다. 같은 날짜에 사용자가 명시적으로 다시 기록할 수 있습니다.

자동 테스트는 임시 상태, 적당함 기준점, 추움·더움 경계, 상충 응답, 먼 기온·실내·삭제 제외, 날짜 중복, 활동·체류 시간 가중치, 추천·수동 비교의 범위 일치를 검증합니다. 브라우저에서는 임시 상태에서 개인 기록 기준으로 전환, 근거 표시·조합 불러오기, 기기별 레이아웃도 확인합니다.

실제 추천 정확도는 학습에 쓴 기록을 재평가하는 대신 이후의 외출 피드백에서 적당함 비율과 심한 추움·더움 비율로 확인해야 합니다.
